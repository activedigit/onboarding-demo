# מערכת קליטת עובדים דיגיטלית — דמו חי

דמו אינטראקטיבי ללקוחות: חברות אבטחה, כוח אדם ומשאבי אנוש. רץ ישירות בדפדפן, בלי התקנה ובלי שרת.

## הפעלה
**אונליין:** https://activedigit.github.io/onboarding-demo/
**מקומית:** לחיצה כפולה על `index.html`.

## מה רואים בדמו
מסך המשרד ומסך הטלפון של העובד, זה לצד זה (בנייד יש מעבר בין שני המסכים בלשוניות):

| מסך | מה אפשר לעשות |
|---|---|
| **עובדים** | מדדים, חיפוש וסינון, יצירת עובד חדש (עם או בלי שליחת קישור), ייצוא הטבלה לקובץ Excel (CSV) |
| **הטלפון של העובד** | הודעת WhatsApp עם קישור אישי · פרטים אישיים · צילום ת.ז וספח · **טופס 101 בהעלאה בלבד** (צילום או PDF, בתוקף עד סוף שנת המס) · חתימה דיגיטלית על שאר הטפסים · העלאת מסמכים עם תאריך תוקף |
| **תיק עובד** | מתעדכן בזמן אמת · צפייה בכל טופס ומסמך · אישור פריט או בקשת תיקון · אישור קליטה |
| **עריכה מהמשרד** | כל פרט בתיק ניתן לעריכה ושמירה: שם, ת.ז, טלפון, תאריך לידה, כתובת, תפקיד, תאריך תחילת עבודה, ימי עבודה, הצהרת בריאות, מסלול מסמכים ואתר שיבוץ · העלאה והחלפה של כל מסמך מהמשרד · עדכון תאריכי תוקף · שליחת קישור קליטה מתוך התיק |
| **התראות** | מסמכים שפג תוקפם, תוקף שמסתיים ב-30 יום (בקשת חידוש או עדכון תוקף), עובדים שלא התקדמו, תיקים לבדיקה |
| **הודעות שנשלחו / בהמתנה לשיבוץ / הגדרות** | יומן הודעות, שיבוץ לאתר, מסלולי מסמכים |

למעלה יש מדריך של 5 צעדים, וכפתור "רוצים את זה אצלכם?" שפותח WhatsApp למספר 054-329-0250.

## נתוני הדגמה
כל השמות, המספרים והמסמכים הם **דוגמאות בדיוניות**. התאריכים מחושבים יחסית להיום, כך שההדגמה תמיד עדכנית.
שום פרט לא נשמר ולא נשלח: הכול קורה בזיכרון של הדפדפן, וכפתור "איפוס" מחזיר הכול להתחלה.
קובץ שמעלים בדמו נשאר רק בדפדפן של מי שמשתמש בו.
